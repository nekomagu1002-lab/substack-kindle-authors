# 日本語Substack × Kindle著者一覧

日本語でSubstackを発信し、Amazon Kindleでも著書を確認できた人をまとめる公開ページ用リポジトリです。

## 公開方針

- `index.html` をGitHub Pagesの公開本体として使用
- 公開ページには読者向け情報のみ掲載
- 調査用Excel、保留候補、A/B/C判定、内部検証ログは原則としてこの公開リポジトリへ置かない
- Kindle Unlimitedや販売状況は変動するため、公開ページに最終確認日を明記する

## 今後の構成

```text
substack-kindle-authors/
├─ index.html
├─ README.md
└─ archive/
```

現在の `index.html` はGitHub Pagesの疎通確認用の仮ページです。
